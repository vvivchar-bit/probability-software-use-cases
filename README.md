# Практичні приклади застосування теорії ймовірностей в ІПЗ

**Виконав:** Вівчар Вадим Вікторович  
**Група:** АЛК-43  
**Факультет:** Інженерія програмного забезпечення  

---

## Опис проєкту

Цей репозиторій містить інтерактивний вебприклад застосування формул теорії ймовірностей та математичної статистики в інженерії програмного забезпечення.

Мета проєкту — показати не лише теоретичні розрахунки, а й практичне використання задач 1–20 у реальних ІТ-сценаріях: тестуванні, DevOps, SRE, балансуванні навантаження, керуванні інцидентами, A/B тестуванні та аналізі продуктивності.

---

## Реалізовані візуальні приклади

У проєкті реалізовано такі інтерактивні вкладки:

1. **Комбінаторика** — використання сполучень для побудови тестових сценаріїв.
2. **SLA** — розрахунок надійності послідовної та резервної архітектури.
3. **Балансування** — класична ймовірність у задачі розподілу запитів між серверами.
4. **Байєс** — визначення найімовірнішої причини інциденту.
5. **Пуассон** — аналіз аномального мережевого трафіку.
6. **A/B тест** — оцінка статистичної значущості результату.
7. **CDF** — емпірична функція розподілу для аналізу часу завантаження сторінки.
